# 🛒 Lista de Compras em C

Projeto desenvolvido em linguagem C para gerenciamento de uma lista de produtos, permitindo criar, visualizar, editar e remover itens.

## 📌 Funcionalidades

* Criar uma lista de produtos
* Definir o tipo da lista:
  * Comida
  * Limpeza
  * Roupa
* Adicionar produtos com nome, preço e quantidade
* Listar os produtos cadastrados
* Editar produtos
* Remover produtos
* Utilizar alocação dinâmica de memória
* Liberar a memória utilizada pelo programa

## 🛠️ Tecnologias e conceitos

* C
* Structs
* Ponteiros
* Funções
* Alocação dinâmica de memória (`malloc` e `free`)
* Manipulação de arrays
* Estruturas de dados
* Entrada e saída de dados

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/lista-de-compras-c.git
```

### 2. Acesse a pasta

```bash
cd lista-de-compras-c
```

### 3. Compile o programa

Utilizando GCC:

```bash
gcc main.c -o lista
```

### 4. Execute

No Windows:

```bash
lista.exe
```

No Linux/macOS:

```bash
./lista
```
